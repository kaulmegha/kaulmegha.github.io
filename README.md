# Megha Kaul | Personal Website

Live at: https://kaulmegha.github.io/

## Run locally

**With Node:**
```bash
npm install --legacy-peer-deps
npm start
```
Open http://localhost:4200

**With Docker** (requires Docker Hub access):
```bash
docker-compose up --build
```
Open http://localhost:8080
